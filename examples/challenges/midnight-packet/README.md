# Midnight Packet (example)

A minimal example of a **STATIC** challenge package — demonstrates the
manifest format and the `files/` layout. Not a real, solvable CTF
challenge; the referenced file is a placeholder note rather than an actual
packet capture.

To try importing it: zip this directory's contents (`challenge.yml`,
`README.md`, `files/`) so that `challenge.yml` sits at the archive root,
then use **Control Center → Challenges → Import** and supply any flag —
the import always requires you to type the real flag yourself, since
packages never carry one (see `docs/challenges/challenge-packages.md`).
